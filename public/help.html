EasyMark Help

AI-powered Markdown note application / AI 驱动的 Markdown 笔记应用

Getting Started

EasyMark is a local-first Markdown note app with AI assistance. Notes are saved as .md files in your Documents/EasyMark folder.

Creating a Note

Click New Note in the sidebar or press Ctrl+N. Type a title and press Enter.

Saving

Notes auto-save as you type. You can also press Ctrl+S to manually save.

Markdown Editing

The editor works like Typora — it renders Markdown formatting inline as you type.

AI Assistant

Click the person icon in the title bar to open the AI panel. Before using AI, go to Settings → AI and enter your API key.

  • Write tab: Get suggestions or completions for selected text
  • Chat tab: Chat with AI about your note

You can also click Refresh in Settings → AI to fetch available models from your API.

Search & Replace

Press Ctrl+F to open the search bar. Use Enter / Shift+Enter to navigate matches. Click Replace or All to replace text.

Images

Paste an image from your clipboard directly into the editor. Images are saved to the assets/ folder next to your notes.

Outline

Click the list icon in the editor toolbar to open the outline panel. Click any heading to jump to that section.

Settings

Click the gear icon in the title bar to open settings:

  • Appearance: Theme (light/dark), color scheme (Forest/Ocean/Terracotta/Monochrome), language
  • AI: API key, base URL, model selection with refresh
  • About: Version info

快速开始

EasyMark 是一款本地优先的 AI Markdown 笔记应用。笔记以 .md 文件保存在 Documents/EasyMark/ 目录下。

新建笔记

点击侧边栏的「新建笔记」按钮或按 Ctrl+N。输入标题后按回车确认。

保存

笔记自动保存。也可以按 Ctrl+S 手动保存。

AI 助手

点击标题栏的「人物图标」打开 AI 面板。首次使用需在「设置 → AI」中输入 API Key。

  • 写作：对选中文本获取建议或补全
  • 对话：与 AI 讨论你的笔记内容

在「设置 → AI」中点击「刷新」可从 API 拉取可用模型列表。

搜索替换

按 Ctrl+F 打开搜索栏。Enter / Shift+Enter 上下导航。点击「替换」或「全部」进行替换。

图片

直接从剪贴板粘贴图片到编辑器中。图片自动保存到笔记同目录的 assets/ 文件夹。

大纲

点击编辑器工具栏的「列表图标」展开大纲面板。点击标题跳转到对应位置。

设置

点击标题栏的「齿轮图标」打开设置：

  • 外观：主题（亮/暗）、配色（森林/海洋/陶土/黑白）、语言
  • AI：API Key、地址、模型选择（支持刷新）
  • 关于：版本信息
